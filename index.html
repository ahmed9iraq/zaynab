SQL Database • شرح الأوامر الأساسية

SQL Database

شرح مبسط للأوامر البرمجية الخاصة بإنشاء قاعدة البيانات، اختيارها، ثم حذفها باستخدام SQL Server.

تم تصميم هذا الموقع بواسطة أحمد

1. إنشاء قاعدة بيانات — CREATE DATABASE

لإنشاء قاعدة بيانات جديدة في SQL Server نستخدم الأمر CREATE DATABASE.

1
افتح SQL Server Management Studio وافتح نافذة New Query.
2
اكتب الأمر التالي، مع استبدال db_name بالاسم الذي تريده.
CREATE DATABASE db_name;

مثال

CREATE DATABASE dbStudents;
هنا قمنا بإنشاء قاعدة بيانات اسمها dbStudents. بعد تنفيذ الأمر ستظهر قاعدة البيانات ضمن Databases.
النتيجة: أصبحت لدينا قاعدة بيانات جديدة يمكننا العمل بداخلها.

2. اختيار قاعدة البيانات — USE

بعد إنشاء قاعدة البيانات، نحتاج إلى تحديد قاعدة البيانات التي نريد العمل عليها. لهذا نستخدم الأمر USE.

الصيغة

USE db_name;

مثال

USE dbStudents;
الأمر USE يخبر SQL Server بأن قاعدة البيانات التي نريد تنفيذ أوامر العمل عليها هي dbStudents.

التسلسل

CREATE DATABASE dbStudents;
USE dbStudents;
مهم: نستخدم USE بعد إنشاء قاعدة البيانات حتى نحدد قاعدة البيانات التي نريد العمل عليها.

3. حذف قاعدة البيانات — DROP DATABASE

الأمر DROP DATABASE يستخدم لحذف قاعدة بيانات كاملة.

الصيغة

DROP DATABASE db_name;

مثال

DROP DATABASE dbStudents;
تحذير: الأمر DROP DATABASE يحذف قاعدة البيانات ومحتوياتها، لذلك يجب استخدامه بحذر.

ملاحظة مهمة عن USE والحذف

قبل الحذف يجب ألا يكون اتصالك الحالي يستخدم قاعدة البيانات المراد حذفها. لذلك إذا كنت داخل dbStudents وانتقلت إلى حذفها، استخدم قاعدة أخرى مثل master أولًا.

USE master;
DROP DATABASE dbStudents;
الترتيب العملي: أنشئ القاعدة بـ CREATE DATABASE، ثم اخترها بـ USE عند العمل عليها. وعند الرغبة في حذفها، انتقل إلى master ثم نفّذ DROP DATABASE.

الخلاصة

الأوامر الأساسية في هذا الموقع:

DROP DATABASEحذف قاعدة البيانات
مثال كامل:

USE dbStudents;
